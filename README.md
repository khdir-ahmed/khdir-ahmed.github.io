# Ahmed Khdir — Portfolio

Personal portfolio and online CV: **https://khdir-ahmed.github.io/**

Built with **React 19**, **TypeScript**, **Tailwind CSS v4** and **Motion** (scroll reveals, layout animations, cursor spotlight), bundled with **Vite** and deployed to **GitHub Pages** with GitHub Actions.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Editing content

All text lives in [`src/data.ts`](src/data.ts): profile, projects, experience, skills, activities, certifications, education and languages. Add a project there and it appears on the site automatically. Project images go in `public/projects/`.
